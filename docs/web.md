# Web 介面使用說明

`sip-faxd` 內建 Web 介面，不需要另外安裝。介面提供繁體中文與英文。

## 1. 連線與登入

- 預設網址：`https://<伺服器位址>:8443/`。設定檔沒有 `[web]` 也會啟動；不需要時在設定檔寫 `[web]` `enabled = false`。
- 沒有提供自己的憑證時，伺服器使用自簽憑證，瀏覽器會出現警告。請把啟動 log 中的 SHA-256 指紋和瀏覽器顯示的憑證指紋比對，相同才繼續。自簽憑證有效期 825 天，到期前 30 天自動更新（指紋會改變，需要重新確認）。
- **第一個管理員**：第一次啟動時建立帳號 `admin`，密碼在 `conf/initial-admin-password`。第一次登入必須設定新密碼（至少 10 個字元，不能和帳號相同），改完後該檔案會被刪除。
- 同一個帳號連續輸入錯誤密碼 5 次會鎖定 15 分鐘；同一個來源 IP 每分鐘最多嘗試 20 次。
- 閒置 8 小時（`[web] session_idle_hours`）或登入滿 7 天後需要重新登入。

**還沒有設定中繼時**，每個頁面上方會顯示提示：管理員看到「尚未設定中繼」與前往 設定 → 中繼 的連結；座席看到「尚未設定電話線路，請聯絡管理員」。新增中繼後提示自動消失。

## 2. 角色

| 功能 | 座席 | 管理員 |
|---|---|---|
| 傳真列表、內容、下載 | ✅ | ✅ |
| 切換已讀／未讀、編輯備註 | ✅ | ✅ |
| 看投遞狀態 | ✅ | ✅ |
| 重新投遞 | | ✅ |
| 設定、帳號、稽核紀錄 | | ✅ |
| 系統狀態 | ✅ | ✅ |

座席直接輸入設定頁的網址也只會看到「沒有權限」。

## 3. 傳真列表

- 未讀的傳真以粗體顯示，左側有色條。上方的「全部／未讀／已讀」可以快速切換。
- 「篩選」可依狀態、日期（當地時間的整天）、發話號碼開頭、受話號碼開頭、中繼篩選。搜尋框會在發話號碼、受話號碼、對方識別（TSI）與備註中任何位置比對，不分大小寫。
- 往下捲動會自動載入下一批；也可以按「載入更多」。
- **即時更新**：正在接收的傳真會顯示「接收中，第 N 頁」，收完自動變成「完成」或其他結果，不需要重新整理。畫面右上角的圓點表示即時連線狀態（實心：已連線；空心：中斷，正在重新連線）。
- 你往下捲動、或正在看其他頁面時，新傳真不會插到最上面打斷你，而是顯示「有 N 份新傳真，按這裡顯示」。
- 每一列右側的按鈕可以直接切換已讀／未讀。

## 4. 傳真內容

- 左側是各頁縮圖，右側是整頁預覽。可以用「上一頁／下一頁」、鍵盤的左右方向鍵（或 Page Up／Page Down）、或點縮圖換頁；「縮放」可選符合寬度或 50%–200%。
- 「下載 PDF」「下載 TIFF」下載原始檔案。
- **開啟傳真不會自動標為已讀**，請按「標為已讀」。誰在什麼時候改了已讀狀態會顯示在詳細資料中。
- **備註**：輸入後按「儲存備註」。如果在你編輯期間別人先存了備註，儲存時會提示「備註已被 X 修改」並顯示對方的版本，你可以選「改用對方的版本」或「用我的版本覆蓋」。你沒有在編輯時，別人存的備註會直接更新到畫面上。
- 詳細資料包含號碼、對方識別、時間、通話長度、頁數、結束原因、解析度、速率等。
- **投遞**：列出每個投遞目的地的狀態、嘗試次數、下次嘗試時間與最後的錯誤。管理員在有「失敗」或「已放棄」的投遞時可以按「重新投遞」。
- 檔案已依保存期限清除時，頁面會說明清除的時間，只保留紀錄。

## 5. 設定（管理員）

左側選擇區段：SIP、媒體、通話、通話擷取、中繼（trunk）、投遞路由、投遞參數、保存期限。

- 修改後按「儲存」。設定在**下一通來電**生效，進行中的通話不受影響。
- 標示「變更後需要重新啟動服務才會生效」的欄位（例如 SIP 監聽位址、T.38 埠範圍、通話擷取），儲存後頁面上方會列出等待重啟的設定；以 `sip-faxd restart`（或 `systemctl restart`）重啟後生效。
- 欄位有錯時，錯誤會顯示在該欄位旁，整個區段不會被儲存。
- 兩個管理員同時修改同一個區段時，後儲存的人會看到「這個區段已被其他人修改」，請按「重新載入」後再修改。
- 標示「（預設）」的欄位留空表示使用預設值。清單欄位一行一個值。
- **密碼與金鑰**（註冊密碼、Email 密碼、Webhook HMAC 金鑰）不會顯示，只會顯示「已設定／未設定」。要更換時輸入新值；勾選「清除」可刪除。沒有輸入時保留原值。
- **中繼**：可新增、刪除與調整順序。來電依序比對，第一個「允許的來源 IP」包含來源位址的中繼處理這通電話。
- **投遞路由**：依序比對，第一條符合的路由會執行它的全部投遞方式。條件（受話號碼、受話號碼開頭、中繼）全部成立才符合；「預設路由」符合所有傳真，必須放在最後。每條路由可以有多個投遞方式（資料夾、Email、Webhook）。
- 所有設定變更都記在「稽核紀錄」，可以展開看變更前後的內容。

## 6. 帳號（管理員）

- 新增帳號時設定角色、初始密碼與介面語言；預設勾選「下次登入時必須變更密碼」。
- 編輯帳號可以改顯示名稱、角色、語言、停用，或重設密碼。停用、降級或重設密碼會立刻結束該帳號所有登入。
- 不能停用、降級或刪除最後一個啟用中的管理員。
- 也可以用指令管理：`sip-faxd user list|add|passwd|disable|enable`。

## 7. 語言

- 介面依序使用：帳號設定的語言 → 這個瀏覽器上次選的語言 → 瀏覽器語言 → 繁體中文。
- 畫面右上角的語言選單只改這個瀏覽器；在「我的帳號」可以把語言存到帳號（在任何瀏覽器登入都使用）。

## 8. 系統狀態

顯示服務狀態、版本、啟動時間、SIP 監聽位址、進行中的通話數、資料庫狀態、各中繼的註冊狀態，以及等待重啟的設定。通話數與註冊狀態即時更新。

## 9. 常見問題

- **瀏覽器說憑證不安全**：自簽憑證的正常現象，比對指紋後繼續；或在 `[web]` 設定自己的 `cert`／`key`。
- **右上角圓點一直是空心**：瀏覽器到伺服器的 WebSocket 被擋（例如中間的 proxy 不支援 WebSocket）。列表仍可使用，只是不會即時更新。
- **頁面顯示「Web 介面沒有建置進這個執行檔」**：這是從原始碼建置、沒有先建置前端的執行檔。正式發佈的執行檔一定包含介面。
- **忘記管理員密碼**：在伺服器上執行 `sip-faxd user passwd admin`。
